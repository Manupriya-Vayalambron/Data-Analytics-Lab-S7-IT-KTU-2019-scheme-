
# Data Analytics Lab – R Programming

A collection of R programming experiments, practical exercises, and examination preparation materials for the Data Analytics Laboratory.

## 📚 Repository Contents

This repository includes:

- **Lab Experiments:** Programs and solutions for all the experiments covered in the laboratory.
- **Internal Examination Questions:** Questions and programs from internal examinations.
- **Other College Questions:** Questions collected from Data Analytics Labs of other colleges.
- **Important Questions:** Important and frequently practised questions for examination preparation.
- **Additional Practice Programs:** Extra programs and examples to improve practical knowledge.

## 🧪 Topics Covered

- R Programming Basics
- Vectors and Matrices
- Data Frames and Data Manipulation
- Statistical Operations
- Data Visualization
- Histogram, Box Plot and Scatter Plot
- Titanic Dataset Analysis
- Data Preprocessing
- Linear Regression
- Decision Tree
- Random Forest
- Clustering and Classification

*The repository will be updated as more experiments and questions are added.*

## 🎯 Purpose

This repository aims to bring together lab experiments, programming solutions, and useful examination resources in one place. It serves as a reference for practising R programming, revising concepts, and preparing for internal and practical examinations.

Suggestions, corrections, and additional questions are welcome. Feel free to contribute useful programs and examination resources.
